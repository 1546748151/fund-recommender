# 基金推荐工具 (FundRecommender) - 设计文档

## 概述

基金推荐工具是一个 Python 流水线 + 静态 HTML 的量化选基系统。从 akshare 拉取中国公募基金数据，通过三维加权打分模型对基金进行同类排名，输出 CLI 报告和静态网站。

**设计参考**：qlibAssistant 的流水线架构 + anthropics/financial-services 的分析方法论。

## 目标用户

个人投资者，希望有一个数据驱动的基金筛选工具来辅助投资决策。

## 功能范围

### 基金类型覆盖
- 股票型、混合型、指数型、债券型、货币型 — 全部公募基金

### 核心功能
1. **数据管理** — 从 akshare 拉取基金净值、排名、经理、费率等数据，本地 SQLite 存储
2. **打分引擎** — 三维加权打分（风险调整收益 45% + 中长期业绩 35% + 基金质量 20%），同类内百分位排名
3. **CLI 报告** — fire 驱动的命令行，支持排名表格和单基金详情卡片
4. **静态网站** — 排行榜 + 图表 + 详情页，GitHub Pages 托管
5. **历史追踪** — 每次运行保存快照，支持评分变化趋势分析

### 不做的事
- 不预测基金未来收益（和 qlibAssistant 的 ML 预测不同，我们做的是基于历史数据的质量打分）
- 不执行交易（纯信息工具）
- 不管理持仓组合（未来可迭代）

## 核心模块

### 1. 数据层 (fund/data)

**数据源**：akshare 公募基金接口

| 接口 | 用途 | 关键字段 |
|------|------|---------|
| `fund_open_fund_rank_em` | 基金排行 | 代码、名称、类型、近1/2/3年收益、规模 |
| `fund_open_fund_info_em` | 单基金详情 | 费率、成立日、跟踪标的 |
| `fund_share_hold_em` | 持有人结构 | 机构占比、内部持有 |
| `fund_announcement_em` | 经理信息 | 从业年限、历任基金 |
| `fund_nav_em` | 净值历史 | 日期、单位净值、累计净值 |

**存储**：SQLite 本地单文件

- `funds` — 基金基本信息 + 最新排名快照
- `fund_nav` — 净值历史（计算回撤、波动率、夏普）
- `fund_managers` — 经理信息

**更新策略**：增量更新，保留历史快照。

### 2. 打分引擎 (fund/score)

**公式**：`Total_Score = 0.45 × RiskAdj + 0.35 × Perf + 0.20 × FundQuality`

**维度一：风险调整收益 (45%)**
| 子指标 | 权重 | 说明 |
|--------|------|------|
| 夏普比率 | 15% | (年化收益-无风险利率)/年化波动率 |
| 最大回撤 | 15% | 历史最大净值回撤幅度，越小越好 |
| 卡玛比率 | 15% | 年化收益/最大回撤 |

**维度二：中长期业绩 (35%)**
| 子指标 | 权重 | 说明 |
|--------|------|------|
| 近1年收益排名 | 10% | 同类内百分位 |
| 近2年收益排名 | 10% | 同类内百分位 |
| 近3年收益排名 | 10% | 同类内百分位 |
| 年化波动率 | 5% | 越低越好 |

**维度三：基金质量 (20%)**
| 子指标 | 权重 | 说明 |
|--------|------|------|
| 规模适中 | 5% | 1-50亿最优，分段打分 |
| 费率合理 | 5% | 管理费+托管费，越低越好 |
| 成立年限 | 5% | ≥3年优先 |
| 机构占比 | 5% | 20-60%最优，适中为佳 |

**关键规则**：
- 同类排名，不跨类比较（股票型和股票型比，债券型和债券型比）
- 所有子指标转为同类内百分位 (0-100) 后加权，消除量纲差异
- 权重通过 config.yaml 配置，不改代码

### 3. CLI 命令 (fund/cli)

```bash
# 数据
python fund.py data update                    # 全量更新
python fund.py data update --type stock       # 按类型更新

# 打分
python fund.py score run                      # 全量打分
python fund.py score run --top 20             # 每类 Top 20
python fund.py score run --date 2026-05-17    # 指定日期

# 报告
python fund.py report table                   # 终端排名表
python fund.py report table --type hybrid     # 按类型过滤
python fund.py report card --code 110011      # 单基金详情卡片

# 页面
python fund.py page build                     # 生成静态网站
python fund.py page serve                     # 本地预览
```

入口：`fire.Fire(FundAdvisor)`，和 qlibAssistant 同模式。

### 4. 静态网站 (fund/page)

**技术选型**：纯 HTML/CSS/JS + ECharts，零运行时依赖。

**设计源**：前端 UI 由 Open Design 驱动设计。OD 项目位于 `D:\dev\open-design\.od\projects\4e53d8f3\`，包含 `index.html`（排行榜）和 `detail.html`（详情页）两个设计稿。PageBuilder 读取 OD 设计稿作为 HTML 模板，提取 CSS 样式，注入动态数据和 JS 交互逻辑后输出最终页面。

**页面结构**：

**首页 (index.html)**
- 概览卡片：覆盖基金总数 + 各类型 Top1 速览
- 类型筛选标签 + 排序下拉
- 排行榜表格：排名/名称/代码/类型/总评分/子维度得分/近1年/近3年/最大回撤/规模/费率
- 表头可点击排序
- 底部三图：类型平均评分柱状图 + Top50 风险收益散点图 + 推荐类型分布饼图

**详情页 (detail.html?code=110011)**
- 基金基本信息
- 净值走势曲线 + 回撤曲线 (ECharts)
- 评分雷达图
- 推荐理由文本（基于评分维度自动生成）

**历史页 (history.html)**
- 评分变化趋势折线图
- 排名变动表

### 5. 自动化调度

GitHub Actions 定时触发（参考 qlibAssistant）：
- `data.yml` — 每日拉取最新数据
- `score.yml` — 打分 + 生成页面
- `deploy.yml` — 部署到 GitHub Pages

支持本地手动跑和 CI 自动跑两种模式。

## 非功能需求

- **可配置**：评分权重、Top N 数量、筛选阈值均通过 config.yaml 配置
- **可复现**：每次打分结果带日期快照，历史可查
- **免责声明**：页面显著位置标注"不构成投资建议"
- **性能**：全量数据更新 < 5 分钟，打分 < 30 秒
- **维护**：零外部服务依赖，akshare 是唯一数据源

## 风险与限制

1. **akshare 稳定性** — 依赖东方财富等第三方数据接口，可能因反爬或维护而中断
2. **基金清盘/合并** — 需处理基金代码变更和退市
3. **打分模型局限性** — 历史表现不代表未来收益，模型仅做质量排序不保证回报
4. **日均数据量** — 8000+ 只基金的全量净值拉取可能触发限流，需控制频率

## 免责声明

本工具仅提供基于历史数据的基金质量评分和排序，不构成任何投资建议。评分高低不预示未来表现。投资者应独立决策并承担风险。
